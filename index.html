01 — About

Background & philosophy

I build mobile products that hold up on the low-end Android devices most Indian users actually carry.

Seven years across React Native, Flutter and native Android — most of it in fintech, where a dropped frame is an annoyance and a dropped transaction is a support ticket. I spent nearly two years at NPCI on BHIM, India's national UPI app, owning app size, crash and ANR rates, and code quality across both the React Native screens and the native Android modules underneath them.

I'm comfortable across the whole mobile surface: native modules, the React Native bridge, state management, API integration, and performance work that starts with a profiler rather than a guess. At Jiraaf I work full-stack — Flutter on mobile, Next.js on the web, Node.js behind both.

My bias is toward root causes over symptoms. Strip the dependency instead of patching around it, fix the bridge instead of catching the crash, tighten the types instead of writing the fifth regression test. Boring systems, small binaries, few surprises.

05 — Side projects

Things I build on my own time

Personal projects — built to scratch an itch, learn something new, or find out where an idea breaks. Source is private; happy to walk through any of them.

Web · Shipped to a real user

MistriBook

Quotation, bill and invoice app for Indian labour contractors — built first for a wooden-furniture contractor in Dombivli who was writing bills by hand. Rates autocomplete from past work, totals render in the Indian number format, and Preview prints straight to PDF on the contractor's own letterhead. The whole app is one self-contained HTML file with no build step, so it opens offline from a phone; Firestore and Google sign-in were layered on afterwards for cross-device sync.

  • Vanilla JS
  • Firebase
  • Firestore
  • Offline-first
Flutter · GPU shaders

ReGrade

Makes phone photos look like they were shot on a real digital camera. Every pixel operation runs on the GPU through Flutter fragment shaders on Impeller — S-curve contrast, a trilinear-interpolated 33-point .cube LUT, grain and vignette in a single draw call. Nothing leaves the device, and the look is just a LUT file, so a new style is a drop-in swap rather than a code change.

  • Flutter
  • Dart
  • GLSL
  • On-device
React Native · New Arch

Triage

A task manager built around the Eisenhower matrix: tasks carry a quadrant and a life area and move across a mobile Kanban board, framed in a flight-deck aesthetic. Bare React Native CLI on the New Architecture (Fabric + TurboModules, Hermes) with React 19 and the React Compiler, strict TypeScript and Material 3. Side effects are injected into the store, so the reducer and selectors stay pure and testable; backup is a JSON file through the share sheet — no account, no backend.

  • React Native
  • TypeScript
  • Reanimated
  • Jest + RNTL
React Native · Canvas editor

Certifi

A certificate designer that runs entirely on a phone. Eleven backgrounds — guilloché, art deco, laurel crest — are drawn as parametric SVG rather than shipped as images, so they stay sharp at any export size. The editor is a real canvas: draggable elements with alignment guides, a layers panel and a style panel. Feed it a recipient list and it batch-renders one personalised PNG or PDF per name.

  • React Native
  • TypeScript
  • SVG
  • Gesture Handler
Desktop · Windows

FetchFlix

A Material 3 desktop front-end for yt-dlp that exposes every option rather than the usual five, laid out across nine panels. A live queue handles pause, resume and auto-retry, and it detects Windows suspend/resume so downloads interrupted by sleep restart themselves. ffmpeg is bundled, so the whole thing ships as one folder — no Python on the target machine.

  • Python
  • PySide6
  • yt-dlp
  • PyInstaller
CLI + GUI

FileTagr

Tag any file on disk — any type, any folder — and find it again by tag combination. Tags live in a local SQLite database, so the original files are never touched and nothing depends on a filesystem that supports metadata. Same binary serves both audiences: pass arguments and it's a CLI, double-click it and it opens a Material 3 Qt desktop UI.

  • Python
  • SQLite
  • PySide6
  • pytest
